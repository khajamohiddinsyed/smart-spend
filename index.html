How to install the APK on Android
  1. Tap Download APK and open the file when the download finishes.
  2. If Android blocks it, tap Settings and allow Install unknown apps for your browser or Files app.
  3. Go back and tap Install. Play Protect may warn that it doesn’t recognise the app because it isn’t from the Play Store; choose Install anyway.

To check the download, its SHA-256 checksum is c36a7e4a50248e64da079f2005b125e4383286f1f9350597e75a672a10fbba65.

How to add the web app to your iPhone home screen
  1. Open the web app in Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Open Smart Spend from the new icon. It launches full screen like an app.
